# Changelog

## 1.0.0 — 2026-11-01

First release.

- Tokens: 33 themed colours and shadows (neutrals, accent, states, 12 system colours, 4 materials), 7 spacing steps, 4 radii, 3 blur radii, 3 layout widths, 17 type styles across UI, display and reading sets.
- Components: Button, TextField, Toggle, SegmentedControl, ListGroup, Materials, SystemColors, SiteHeader, SiteFooter, ArticleHeader, Prose, CodeBlock, Figure, Callout, TableOfContents, Tag, PostCard, PostList, AuthorBio, PrevNext, Newsletter.
- Light and dark themes, following the OS by default.
- Build (`npm run build`) and contrast check (`npm run check`) scripts, no dependencies.
