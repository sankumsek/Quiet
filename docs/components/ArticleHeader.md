# ArticleHeader

The top of a post: a tag, the title, a one-sentence dek and a byline row.

Title uses `article-title` with balanced wrapping; the dek uses `article-dek` in `ink-secondary`; the meta row is `subheadline` with middle-dot separators and the author name in ink. One tag is ideal, two at most. Sits inside `.q-measure` so it lines up with the body text. Consumer provides title, dek, date, reading time and author.
