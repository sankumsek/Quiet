# Button

Buttons trigger an action; use one primary per view and let the rest step down.

- **Primary** (`q-btn--primary`): `accent` fill, `on-accent` label. The single most important action.
- **Secondary** (`q-btn--secondary`): `accent-soft` fill, `accent` label. Supporting actions.
- **Plain** (`q-btn--plain`): text only, for Cancel, Back and inline actions.
- **Destructive** (`q-btn--danger`): `danger` text. Confirm before acting.

Labels are short verbs in sentence case. Corners are `radius-md`; minimum height 40px. Hover and press dim opacity rather than shifting colour. Consumer provides the label and click handler.
