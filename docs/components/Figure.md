# Figure

An image (or video, or embed) with a short caption.

Media gets `radius-md` and a `surface-sunken` placeholder while loading; captions are `footnote` in `ink-secondary`, centred. Add `q-figure--wide` to break out of the reading column to `width-wide` on large screens (it falls back to column width on phones). Always provide alt text; the caption is not a substitute. Consumer provides the media, alt and caption.
