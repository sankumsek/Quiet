# PostList

The dense alternative to cards: one row per post, for archives, "all writing" pages and year groupings.

Each row is a single link: title (headline) and right-aligned tabular date on the first line, optional excerpt below. Hairline `separator` rules between rows; the title turns `accent` on hover. Group by year with a `title-3` heading above each list. Consumer provides title, date, excerpt and link.
