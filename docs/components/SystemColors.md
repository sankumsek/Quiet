# SystemColors

Twelve content colours, matching Apple's system palette in both themes, for giving things identity rather than interactivity.

Use them for category tags, list-row icon tiles, chart series, calendar colours, avatars and illustration. Do not use them for buttons, links or selection — that is `accent`'s job. Orange, yellow, green, mint, teal and cyan fail 3:1 on white in the light theme: in light, use them as fills with `ink` text or glyphs on top, never as text or thin icon colour. Each token's usage note gives its exact contrast.
