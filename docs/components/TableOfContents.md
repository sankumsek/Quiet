# TableOfContents

"On this page" navigation for long posts, shown in a sticky side column on wide screens and above the body (or hidden) on phones.

Built from the post's `h2`s and optionally `h3`s (indented, smaller). The current section — set `aria-current="true"` from a scroll observer — gets `accent` text and an accent bar on the left rail. Only use it for posts with four or more sections. Consumer provides the headings and current-section tracking.
