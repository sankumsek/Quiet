# Tag

A topic label: a pill tinted from one system colour, with a full-strength dot and ink text.

Set the colour per topic with `style="--tag: var(--system-indigo)"` (defaults to accent). The tint is 16% of the colour over `surface`, so ink text stays readable for all twelve colours in both themes. Assign each topic one colour and keep it forever. Tags link to their topic page. Consumer provides the label, colour and link.
