# TextField

A filled input with a label above and an optional hint below.

The field rests on `surface-sunken` with no visible border; hover shows `control-border`, focus lifts it to `surface` with an `accent` border and a soft `accent-soft` halo. Errors swap the border and hint to `danger`. Labels are `footnote` in `ink-secondary`; placeholders use `ink-tertiary` and never replace the label. Consumer provides the label, value and validation.
